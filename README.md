# Sri Shanmukha Bio Plantic – Tropical Gardening-inspired presentation demo

A responsive React + Vite demo with a clean botanical/editorial visual direction inspired by the reference site's broad layout approach, without copying its branding or content.

## Included
- Large readable typography and natural imagery
- Homepage and requested catalogue heading: “EXPLORE THE CATALOGUE — Find a plant for your purpose.”
- Searchable sample plant catalogue
- Detailed Hybrid Coconut page with eight guide sections
- Bulk quotation modal (frontend demonstration only)
- Responsive navigation and layouts

## Run
Requires Node.js 18+.

```bash
npm install
npm run dev
```

Production build: `npm run build`

## Limitations
No backend, persistent database, live enquiry delivery, confirmed stock or pricing. Other plants are placeholders. Remote photos require internet. Coconut guidance is educational sample content and must be reviewed against the exact hybrid and current local agricultural recommendations before publication. No AI features are included.
